**Perfect for:** Interview prep • Competitive programming • Learning DSA patterns

## 🎯 Algorithm Patterns

| Pattern | Description | Time | Space |
|---------|-------------|------|-------|
| **Two-Pointers** | Pairs, triplets, validation | O(n) | O(1) |
| **Sliding Window** | Optimal subarray/substring | O(n) | O(1) |
| **Fast & Slow** | Cycle detection, finding middle | O(n) | O(1) |
| **Kadane's** | Maximum subarray sum | O(n) | O(1) |
